# 光伏电站并网验收与缺陷闭环平台

基于 Nuxt3、PrimeVue、Pinia、Nuxt Router、TanStack Query、ofetch、Vite 和 TypeScript 的独立前端工程。Nuxt 提供页面路由和服务端构建，业务数据在浏览器本地持久化。

## 功能

- 方阵、逆变器、汇流箱、变压器和并网点的设备树。
- 绝缘、接地、通信、保护、发电性能等验收项和证书附件。
- 建设单位、设备厂家、运维单位多方处理说明。
- 联合复验轮次、整改退回、带条件接受和关闭校验。
- 并网前完整性与证书有效期检查，签署锁定和交付包导出。

### 可恢复的并网复核链

断网复测回连场景下，设备节点、验收项、证书、缺陷与审计按以下规则接成复核链：

- **双端实测并列**：每个验收项分别保存中心记录（`center`）与设备节点本机记录（`node`），各端版本独立递增，含实测值、证据、记录人与实测时间，任何一端都不覆盖另一端。
- **按时间合并**：回连时以最近合并点为基准；仅一端改动按时间合并，两端实测时间都晚于合并点即判定为「两端并改」，并列保留并标记冲突。
- **负责人选定**：冲突项（或选定后任一端又产生新实测的项）必须由负责人选定一份实测版本，**选定后才参与完整性判定**，双方原始记录继续留存。
- **换版/复测联动失效**：证书换版为不可变版本历史；换版后同设备节点的缺陷立即标记「待重新核对」；复测结论（通过↔不通过）翻转时同样失效。缺陷失效期间禁止作验收决定，重新核对通过后才恢复判定。
- **签署快照**：每次签署冻结设备、验收项、缺陷、审计与完整性结果，并生成规范序列化的内容指纹。证书换版、复测变化等事件会让有效快照转为「已失效」，电站回到「待复核」。
- **幂等签署**：同一幂等键重复提交、或已存在有效签署版本时，重复提交只返回同一份快照，**不会生成第二个签署版本**；任一时刻至多一份有效快照。
- **写入恢复**：签署时最后完整快照先写入 WAL（`gsb67:pending-sign:v2`），再提交主数据；主数据写入失败或崩溃后，下次加载可依据 WAL 从最后完整快照恢复，恢复前校验内容指纹，指纹不符则中止并保留现场。
- **审计哈希链**：审计条目含 `prevHash` 与本环哈希（FNV-1a 64 位，规范化序列化），设备节点、验收项、证书、缺陷、签署五类实体沿链可追溯，页面实时显示链校验结果。

## 校验脚本

```bash
npm install
npm run verify   # 39 项复核链端到端检查：双端冲突、选定、换版失效、复测翻转、幂等签署、WAL恢复、哈希链
npm run build
npm run dev      # 端口 18467
```
