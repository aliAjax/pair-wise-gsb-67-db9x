# 光伏电站并网验收与缺陷闭环平台

基于Nuxt3、PrimeVue、Pinia、Nuxt Router、TanStack Query、ofetch、Vite和TypeScript的独立前端工程。Nuxt提供页面路由和服务端构建，业务数据在浏览器本地持久化。

## 功能

- 方阵、逆变器、汇流箱、变压器和并网点的设备树。
- 绝缘、接地、通信、保护、发电性能等验收项和证书附件。
- 建设单位、设备厂家、运维单位多方处理说明。
- 联合复验轮次、整改退回、带条件接受和关闭校验。
- 并网前完整性与证书有效期检查，签署锁定和交付包导出。

## 可恢复的并网复核链

针对"现场验收员断网复测、回连按时间合并、签署页只看最后一份本机数据"的问题，设备节点、验收项、证书、缺陷与审计按以下规则串成可恢复链路：

- **验收项双端并列**：每条验收项保留 `node`（设备节点/现场离线）与 `center`（中心记录）双方实测，各含实测时间、记录人与端版本；回连后按实测时间并列合并，任何一端都不覆盖另一端。同一验收项两端都改过即进入"双端冲突"，只有负责人选定其中一份后才参与完整性判定；裁定之后若任一端又补来更晚的实测，裁定自动失效并回到冲突。禁止向本端时间线插补更早的记录。
- **证书换版联动失效**：证书换版后新版本默认待核验；引用旧版本的缺陷闭环快照立即标记"失效待核对"，已签署快照同步标记失效（电站回到"待复核"）。新版本核验通过、缺陷重新核对后才允许重新签署。
- **复测结论翻转联动失效**：已闭环缺陷的复测结论相对上一轮发生翻转（通过↔未通过），其闭环快照立即失效，需重新核对；签署快照同样随之失效。
- **可恢复签署**：签署先冻结并落盘"完整快照"（含回滚锚点、数据指纹与审计链头），再执行最终写入。写入失败时业务状态不前进，可按原请求重试（同一幂等令牌、同一快照，不产生第二个版本）；失败后数据若已漂移则拒绝重试，须从最后完整快照回滚恢复。对已锁定版本重复提交只返回幂等提示，绝不另起签署版本；只有重新核对后重签才升版。
- **审计哈希链**：审计条目带序号、前序哈希与内容哈希，逐条可校验，篡改可被检出；每个签署快照指纹锚定冻结时的审计链头。

签署页提供"故障注入：下一次签署写入失败"开关，用于演示写入失败、按原请求重试与快照恢复。

端到端链路规则（46项断言）可用以下命令校验：

```bash
npm run verify:chain
```

端口为`18467`。

```bash
npm install
npm run build
npm run dev
```
